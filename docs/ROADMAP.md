# Roadmap

## Foundation

Establish private GitHub repository, small commits, contribution/security guidance, CI, contextualization, five-perspective decision records. Implement validated types, deterministic research core, durable journal, bounded job state, and shared model-spend reservations.

## Reproducible research

Ingest free real data with provenance. Keep synthetic fixtures separate. Verify time integrity, costs, accounting, adjustments, corporate actions, missing sessions, and reproducible artifacts. Expand provider coverage only under documented rights. Unsupported features reject explicitly.

## Persistent agent desk

Implement research director, hypothesis researcher, experiment engineer, data/implementation critic, and statistical/portfolio critic. Persist exact evidence, prompts/model metadata, decisions, trials, and failures. Independently inspect each integrated increment through criticism, quality, and scope reviewers. Integrate genuine Opus criticism with measured cost controls once configured.

## Controlled evaluation and operation

Freeze specifications, gate final evaluation, track exposure, and prevent misleading pass labels. Add durable scheduling, stale worker fencing, bounded retries, artifact reconciliation, backup restore, operator dashboard, and unattended-run evidence.

## Paper and live execution

Add a separate paper-forward runner with position/order accounting and realistic restrictions. Observe operation. Add a separately credentialed broker adapter, explicit risk configuration, emergency stop, restart and reconciliation checks. Present a concrete strategy and execution plan for explicit owner activation approval before live use.

## Release readiness

Maintain private GitHub until requested otherwise. Audit secrets, dataset rights, dependency licenses, commit history, documentation accuracy, and clean-checkout reproduction before selecting a public license and publishing.
