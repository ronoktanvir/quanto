# Supervision of the next manual research cycle

The proposed supervisor starts one clock before registration. It gives the three local registrations and the subsequent broker invocation a shared 7,200-second allowance on the owner's Mac. The last five seconds are reserved for observing termination. The parent checks elapsed monotonic time and wall time so that time spent asleep also reduces the remaining allowance.

The parent verifies the selected registration, auditor and supervisor reviews, the code and input identities, and the prior research request. It records a one-use intent, invokes the approved registration helper once and checks all three phase records. It then constructs the research request from the original template, changing the run key and suite reference. The authorized failure roster and model assignments retain their original order and identities.

The paid child uses an existing development session. It checks the suite and records the spending observation and journal checkpoint before entering the broker. The parent records ownership, process exit, exact output references and the need for a separate audit. A later auditor must verify the prospective records, the complete returned outcome and any resulting calculations. The lead must separately observe the parent's terminal outcome. The deadline and cleanup checks apply to ordinary process execution. A blocked operating system can leave termination uncertain.
